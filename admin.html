Grand Malabar Admin

Sign in with a GitHub access token to manage your products and site images. Only people with write access to this repository can make changes.

How do I get a token?
  1. Open GitHub → Fine-grained tokens → Generate new token.
  2. Repository access: Only select repositories → choose Malabar.
  3. Permissions → Repository permissions → Contents: Read and write.
  4. Pick an expiry (e.g. 90 days), generate, and paste the token below.

Your token stays in this browser and is only sent to api.github.com. Don't tick “Remember me” on a shared computer.

Replace the photos shown on the website. Images are resized automatically. Changes go live when you press Publish changes.

How publishing works

  • Edits stay in your browser until you press Publish changes. That saves them to GitHub and the live site refreshes in about a minute.
  • Every publish is a normal GitHub commit, so you can see the history and roll back from the repository page.
  • Hidden products stay saved here but are not shown on the website.
